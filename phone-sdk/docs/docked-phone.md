# 常驻手机与视口停靠

本文说明当前工作区的新实现；已有 npm 0.6.0 不包含本次停靠调整。

## 玩家体验

执行「挂载手机」且开启「显示常驻手机」后，真正的手机缩小并移到游戏视口外，仅保留一小段可点击区域。点击露出的机身或使用原快捷键，会展开同一台手机；关闭后沿相同的几何变换收回，保留当前内页。没有额外的 HUD 按钮，也不复制另一份手机。

首页不显示右上角关闭按钮。点击手机外侧完成一次点击后收回手机；这次输入不会推进底层剧情。收回完成后，下一次点击剧情区域才正常继续剧情。

刷新/重新挂载时先测量游戏 UI Host，在首次可见绘制前确定停靠坐标；初始定位不播放展开或收回动画。不会先在屏幕上方显示完整手机再移走。后续展开与收回默认耗时 320ms，并尊重系统的「减少动态效果」。

## 作者设置

在手机编辑器的「手机 HUD」页调整；预览区可点击手机展开、收回。

| 设置键 | 用途与默认值 |
| --- | --- |
| `showPhoneHudButton` | 保留旧键以兼容工程；现在表示显示常驻手机，默认开启 |
| `phoneHudPosition` | 默认 `follow-phone`，跟随作者配置的弹出位置；支持独立指定上/下三档和左/右中部 |
| `phoneHudScale` | 停靠时相对展开手机的缩放，默认 0.6，范围 0.25–1 |
| `phoneHudPeekHeight` | 露出宽度或高度，默认 32，范围 24–96，单位为游戏 UI Host 的 CSS 像素 |
| `phoneHudOffsetX` | 上下边缘沿水平方向的微调，正值向右 |
| `phoneHudOffsetY` | 左右边缘沿竖直方向的微调，正值向下 |

跟随位置时，左上/中上/右上停靠到上边缘，左下/中下/右下停靠到下边缘；居中弹出的手机停靠在下方中间。脚本临时指定的弹出位置不改变作者配置的常驻位置。旧工程已经指定的 `phoneHudPosition` 继续生效。

旧按钮的图标、文字、图片与配色字段不再出现在编辑器或参与渲染；不删除工程中的历史字段值。手机壁纸、主题、APP、玩家设置及存档结构保持原有归属。

## 生命周期与调用

- `mount-phone` 激活手机能力，并按常驻设置显示停靠手机；禁用常驻时仍可使用原快捷键。
- `openPhoneApp` 展开已挂载的手机并导航到目标 APP。`waitUntil: "none"` 不等待关闭，`waitUntil: "close"` 等待收回完成通知。
- `closePhoneApp` 默认等待收回动画完成再释放剧情等待；`animated: false` 直接停靠，不播放过渡。
- 收回不卸载手机组件；隐藏的屏幕使用 `inert`，不响应点击或 Tab，机身以外的区域允许继续操作剧情。
- `unmount-phone`、流程中止或扩展卸载仍清理实际 UI、监听器和等待。
- `PhoneHudExtension` / `phone-hud` 保留兼容导出和 ID，不再挂载独立按钮。

`phone-presentation.ts` 管理每个 Preview 的展开/收回/停靠状态；`phone-dock-layout.ts` 只计算局部坐标和等比缩放；`phone-ui-content.tsx` 负责同一实例的输入、过渡和可访问性。编辑器复用相同的布局计算。
